# Scent Storizes

An immersive perfume library: a wall of real perfume bottles you can zoom and wander, full story pages for Chanel N°5, L’Air du Temps and Terre d’Hermès, and **The Balancing Act**, a perfume quiz where a glass flask leans on a table as the clock runs.

Front end only (React + Vite), no backend or accounts. Ratings and comments are sample data stored in your browser.

```bash
npm install
npm run dev
```

## Photo credits

All photographs come from Wikimedia Commons under their stated licences (public domain, CC0, CC BY and CC BY-SA), with backgrounds removed and crops applied. Each page lists its credits in its footer, and the full list is in `src/data/imageCredits.json` and `src/photoMeta.json`.

Scent Storizes is an independent fan project and is not affiliated with any of the perfume houses shown.
